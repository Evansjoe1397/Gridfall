# Da Orkk on Nagrand

Select **Hotseat → 1 versus 1 → Nagrand → your Character → Da Orkk · Tactical Bot**. You control Player 1; Da Orkk controls Player 2. This always starts Standard mode. Merylin Bot and manual Hotseat opponents remain available. Other arenas, Free For All, Perk Mode and Best-of-Three are outside this bot's scope.

The bot manages Rage as Attack ammunition, pressures melee range, considers High Ground and Quest objectives, and weighs survival against Card preservation. It forecasts Shield throw collisions, recall routes and crossed enemies, HP/Rage creation payments, Kyk directions and momentum, healing and status removal. It handles opening Focus, Phase progression, Spell Echo, defense, Combat Cards and required discards through the same commands and rules as a human.

Finishing forecasts pay Guard/Dash costs and complete mandatory end-turn choices before scoring. Burning carries a future Damage liability, encouraging safe removal through Dash instead of repeating Guard while Burning. Optional discards no longer appear to postpone the same turn's Damage. The profile values several stored Perks, higher Echo levels and legal upcoming shifts with a playable leveled Perk waiting in Hand; immediate wins and useful Attacks can take priority. Destroying a recoverable own Shield is penalized, including through the second search decision. Box attacks receive less value outside The Elephant Quest, while enemy Lens removal and useful destruction remain candidates.

`src/orkk-bot.ts` supplies Da Orkk's Card priorities, resource values and targeting choices. `src/nagrand-bot-core.ts` supplies shared engine validation, hypothetical combat evaluation and bounded search. Targeting sequences are forecast through their results before committing to a Perk. A Kyk target with no selectable on-board direction is excluded; the bot avoids starting an uncompletable targeting sequence. Each real command is followed by a new observation. There is one deterministic heuristic difficulty, with no claim of optimal play.

CountaSpell retains DEF 3. After combat acknowledgement, if its effect was not cancelled and both characters are alive, the defending player chooses any whole number from 0 to their current Rage. Spend that many Rage and add the same number of Headache Cards to the attacker's Discard, following normal status protection and excess-copy rules. Rage gained from this combat is available. Zero spends nothing; zero available Rage skips the choice. Other pending Attack movement/choices finish first. The bot evaluates every legal spending amount through the shared planner. Human Hotseat/online defenders use the amount field and spending buttons; only the defending online seat can choose. `check:countaspell` covers engine timing, protection/cancellation, validation, the production UI renderer with DOM fakes and bot choices. The production Orkk Worker check also verifies this choice.

Both bots use the existing filtered observation boundary in `src/merylin-bot-observation.ts` and Worker in `src/merylin-bot-worker.ts`. These filenames remain for compatibility; the controller and Worker select the appropriate character policy through `src/nagrand-bot.ts`. The Worker never receives the human's hidden Hand, shuffled draw order, unrevealed Attack, private extra Combat Card submission, histories or deferred results. The bot's own shuffled Deck order is also masked. Combat guesses use the opponent's authored character Card pool rather than actual hidden Cards.

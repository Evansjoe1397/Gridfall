# Game icon set

Thirty transparent, indexed-color PNGs live in `src/assets/icons/`. Each is 64 × 64 pixels with a 32-color palette, weighing 667–1,080 bytes. The complete set is 24,889 bytes (24.9 KB). These replace the painted Orkk icons and all character trait/HUD status glyphs, including selection, help, and overhead markers. Numeric badges, status colors, and tooltips remain separate. Vite embeds these small PNGs as data URLs in the app bundle, eliminating separate image requests for both HUD and cached overhead markers.

`src/game-icons.ts` defines the filenames in source-sheet order and renders the images. Rebuild with `python scripts/prepare-icon-atlas.py path/to/generated-sheet.png` (Pillow required). The script crops and centers the glyphs, removes the dark backdrop, resizes with antialiasing, preserves transparent edges, and exports PNGs with a total size budget assertion.

Generated as one sheet with the built-in image generation tool, then cut into individual PNGs. The high-resolution source is not shipped.

## Final generation prompt

Create ONE production sprite atlas for a fantasy tactical board game: exactly 6 columns by 5 rows, 30 icons total in equal rectangular cells on a uniform solid near-black #101815 background. Canvas landscape 6:5 aspect ratio. No grid lines, no labels, no text, no frames. Each icon centered in its cell with 18 percent clear padding on every side, equal visual size. Style: primitive bold angular fantasy pictograms, crisp thick silhouettes, flat limited palette of ivory, muted gold, rust orange, sage green and icy blue. At most 3 flat colors per icon, no gradients, no texture, no shading, no realistic painting, no tiny details, no glow. Readable at 24px. Exact row-major subjects: Row 1: clenched fist; heater shield; lightning blade; four-point magic spark; holy cross; two overlapping diamond silhouettes. Row 2: skull; crossed swords; flame; boot pierced by nail; head with lightning crack for headache; slumped head with sweat drop for exhaustion. Row 3: ice crystal; running boot with speed lines; boot with diagonal prohibition slash; dagger; bow with arrow; open spellbook. Row 4: triangular mountain peak; waving flag; warning triangle with exclamation; curved boomerang; spiral shell; double forward chevrons. Row 5: potion vial containing sword symbol; potion vial containing eye symbol; potion vial containing diamond symbol; three stacked diamonds for stored power; four board tiles; winged boot passing between two vertical barriers. Keep all cells strictly aligned and every icon separate, entirely inside its own cell.
